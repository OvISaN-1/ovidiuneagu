Try it: tuning a slow query

Both queries list every customer with their total spend and latest order. They are written in T-SQL and run unchanged on SQL Server. Here they run in your browser on SQLite, against 40,000 made-up orders with no indexes. The first query reads the Orders table twice for each customer. The second reads it once.

Before

Correlated subqueries 
SELECT c.CustomerID, c.Name,
  (SELECT SUM(o.Amount)
     FROM dbo.Orders AS o
    WHERE o.CustomerID = c.CustomerID
  ) AS TotalSpend,
  (SELECT MAX(o.OrderDate)
     FROM dbo.Orders AS o
    WHERE o.CustomerID = c.CustomerID
  ) AS LastOrder
FROM dbo.Customers AS c
ORDER BY c.CustomerID;

After

One set-based pass with a CTE 
WITH Totals AS (
  SELECT CustomerID,
         SUM(Amount) AS TotalSpend,
         MAX(OrderDate) AS LastOrder
  FROM dbo.Orders
  GROUP BY CustomerID
)
SELECT c.CustomerID, c.Name,
       t.TotalSpend, t.LastOrder
FROM dbo.Customers AS c
LEFT JOIN Totals AS t
  ON t.CustomerID = c.CustomerID
ORDER BY c.CustomerID;
